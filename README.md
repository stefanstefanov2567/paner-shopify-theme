# PanER Fasteners — Shopify тема

B2B каталог за крепежни елементи с режим „Запитване“. Основа: Shopify Dawn 16.0.

## Какво има
| Страница | Секция | Какво прави |
|---|---|---|
| Хедър | `PanER · Хедър` | горна лента, лого, търсене с подсказки (по име, код/SKU, тип), категория до търсенето, фирмен профил, брояч „Запитване“, меню с падащи подкатегории, мобилно меню |
| Начало | `PanER · Hero`, `Категории`, `Как работи`, `Списък`, `ЧЗВ` | избор по параметри, категории с илюстрации, запитване по списък от Excel, често задавани въпроси (+ FAQ schema) |
| Категория / Търсене | `PanER · Категория`, `PanER · Търсене` | подкатегории, филтри с броячи (чипове за кратки стойности, отметки за дълги, превключвател за наличност), активни тагове, сортиране, **таблица по размери** с опаковка, брой и „Добави“, групово добавяне, изглед карти, страници без презареждане, долен панел с филтри на мобилно |
| Продукт | `PanER · Продукт` | снимки, технически чертеж (качен или автоматичен от размерите), норма/ISO/сертификат, наличност, опаковка кутия/кашон/палет, брояч с пресмятане на бройки и тегло, смяна на размера, параметри, документи, „Комплектувай с“ |
| Запитване | `PanER · Запитване` | количката работи като списък за оферта: промяна на брой, премахване, добавяне по код, данни на фирмата (ЕИК, PO, доставка), „Изтегли като PDF“, изпращане като имейл до магазина |
| Контакти | `PanER · Контакти` (шаблон `page.contact`) | форма за запитване с фирма, ЕИК, тема, артикул, количество, срок; контакти и търговци |
| Регистрация на фирма | `PanER · Регистрация` (шаблон `page.b2b-register`) | заявка за фирмен профил: фирма, ЕИК, ДДС, МОЛ, град, дейност, обем, лице за контакт, съгласие |
| Каталог | `PanER · Каталог` (`/collections`) | всички категории, групирани по главното меню |
| Изтегляния | `PanER · Изтегляния` (шаблон `page.downloads`) | каталози, сертификати, технически таблици |
| Страници | `PanER · Страница` | За нас, Общи условия, Доставка… със странично меню |
| 404 | `PanER · 404` | търсене и линкове |
| Футър | `PanER · Футър` | лого, фирма, менюта, контакти |

Мобилно: долна навигация (Каталог, Търсене, Запитване, Профил), карти вместо таблица.

## Настройка в Shopify (еднократно)
1. **Theme settings → PanER · Каталог**: телефон, имейл; „Режим Запитване“ е включен.
   По желание: таг (напр. `b2b`), с който одобрени клиенти виждат цени.
2. **Navigation**:
   - `main-menu` — категориите (с подменюта за падащото меню);
   - меню с handle като колекцията (напр. `boltove`) → подкатегориите на страницата на категорията;
   - `footer` — линкове във футъра.
3. **Pages** (Online Store → Pages → Add page → Theme template):
   - „Контакти“ → шаблон `contact` (адрес `/pages/contact`);
   - „Регистрация на фирма“ → шаблон `b2b-register` (адрес `/pages/registracia`);
   - „Сертификати“ / „Изтегляния“ → шаблон `downloads`;
   - „За нас“, „Общи условия“, „Доставка и плащане“ → шаблон по подразбиране.
4. **Search & Discovery → Filters**: добавете филтри по метаполетата по-долу + Availability.
5. **Settings → Notifications**: имейлът на магазина получава запитванията (Contact form).

## Как работи „Запитване“
- „Добави“ слага артикула в количката на Shopify с опаковката като свойство (без плащане).
- На `/cart` клиентът попълва данните си и изпраща — Shopify праща имейл с всички редове.
- След изпращане списъкът се изчиства.
- Изключите ли „Режим Запитване“, цените се показват навсякъде.

## Вход и регистрация (клиентски акаунти)
От февруари 2026 Shopify поддържа само **новите клиентски акаунти**: вход с еднократен код по имейл, без парола,
на страница, хоствана от Shopify. Затова страниците за вход/профил не са част от темата — бутоните в хедъра
(„Вход“, „Моят профил“, „Изход“) водят към тях автоматично.

Настройка:
1. **Settings → Customer accounts** → включено „Customer accounts“ (новата версия).
2. **Settings → Checkout and accounts → Customize** (или Settings → Customer accounts → Customize):
   качете `paner-logo.png`, основен цвят `#EA580C`, текст `#0F172A`, фон `#FFFFFF`, шрифт Inter.
3. **Theme settings → Logo → Favicon**: `paner-favicon.png`.

Фирмена регистрация и одобрение:
1. Фирмата попълва „Регистрация на фирма“ → заявката идва на имейла на магазина.
2. Проверявате ЕИК и в **Customers → Add customer** създавате клиента (или намирате вече влезлия) и добавяте таг `b2b`
   (същият като в Theme settings → PanER · Каталог → „Покажи цени на клиенти с таг“). Фирмените данни можете да запишете в бележката на клиента.
3. Клиентът влиза с имейла си и вижда цените (ако сте задали таг) и статус „Одобрен фирмен клиент“ в менюто на профила.
