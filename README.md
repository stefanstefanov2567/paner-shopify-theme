# PanER Fasteners — Shopify тема

B2B каталог за крепежни елементи. Основа: Shopify Dawn 16.0.

## Каталожен режим
Theme settings → **PanER · Каталог** → „Каталожен режим“ (включен по подразбиране):
- скрива цени, количка и бутони за покупка;
- на продуктовата страница показва форма „Запитване за цена и наличност“;
- запитванията пристигат на имейла на магазина като контактна форма.

## Секции (Theme Editor → Add section)
- **PanER · Hero** — заглавие, бутони и избор по параметри (норма, диаметър, дължина, клас, покритие)
- **PanER · Категории** — колекции с илюстрация и норми
- **PanER · Как работи** — 3 стъпки
- **PanER · Списък** — запитване по списък от Excel
- **PanER · ЧЗВ** — често задавани въпроси (акордеон + FAQ schema за Google)

## Технически параметри на продукта
Блок **PanER · Параметри** чете метаполета на продукта (namespace `custom`) и показва само попълнените:
`norma`, `iso`, `diameter`, `length`, `thread_length`, `thread_pitch`, `strength_class`,
`material`, `coating`, `head_size`, `packaging`, `drawing` (изображение), `tech_sheet` и `certificate` (файл).

## Филтри
Филтрите в колекциите се настройват от приложението **Shopify Search & Discovery**
(по метаполета или опции на вариантите).

## Нужни страници
- Online Store → Pages → „Контакти“ с шаблон `contact` (адрес `/pages/contact`) — бутонът „Запитване“ води там.
